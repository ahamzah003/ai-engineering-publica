# Week 2 Python Foundations Capstone — Shopping Cart

## What the project is about

It allows a customer to build a shopping cart interactively:

1. It repeatedly asks for an item name until the user enters **`done`**.
2. It asks for the item's price.
3. Negative prices are rejected and skipped.
4. It calculates and displays the total cost of the cart.
5. It reports whether delivery is free or not based on the cart total.

🛒 Curious how this shopping cart works? Download and run the [script](https://raw.githubusercontent.com/ahamzah003/ai-engineering-publica/master/python/projects/week2/ShoppingCart.py) to see it come to life! ✨

## Python Concepts Applied

This project is a progressively built **Shopping Cart program** developed across five tasks. Each task introduces another group of Python concepts, and the final Task 5 combines everything into a small interactive shopping-cart application.

The progression is:

| Stage | Main purpose | Python concepts introduced |
|---|---|---|
| **Task 1** | Delivery Fee Calculator | `if`, `elif`, `else` |
| **Task 2** | Till Total | `while`, `for`, `range()`, `break`, `continue` |
| **Task 3** | Name Tag | String methods, indexing, slicing, f-strings |
| **Task 4** | Shopping List | Lists, `.append()`, `.remove()`, membership, tuples, `enumerate()` |
| **Task 5 — Capstone** | Shopping Cart | Combines the concepts above |

### Instructions and restrictions

The instructor explicitly stated that **everything from the previous week is allowed throughout**

At this stage, the following are explicitly **not allowed yet**:

- Dictionaries
- Sets
- User-defined functions (`def`)
- `try` / `except`
- Imports


## Overall project idea

In simple terms, **this week's capstone is a command-line shopping-cart system that demonstrates how progressively introduced Python control-flow, string, and collection concepts can be combined into a single practical application.**

The project moves beyond simply calculating values: it begins to demonstrate how Python can **accept repeated user input, manage structured data, process that data, and produce a useful summary**.
